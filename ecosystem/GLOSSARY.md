# Public terminology

| Term | Meaning |
|---|---|
| Fact | A recorded event or state, with source and context; not automatically a conclusion. |
| Exact knowledge version | An immutable knowledge identity plus version and digest used by an evaluation. |
| Governance evaluation | A deterministic calculation over facts, knowledge and explicit rules/boundaries. |
| Evidence | Material that supports inspection and replay; not by itself authorization. |
| Authorization | Permission granted by an accountable human, organization or external system. |
| Observation | A bounded, explainable finding; not an automatic punishment or production command. |
| Replay | Reconstructing an evaluation with pinned inputs, versions and rules. |
| UNKNOWN | An explicit result when evidence or knowledge is insufficient; not a hidden failure. |
| Roadmap | Planned direction. It is not evidence of implementation or release. |

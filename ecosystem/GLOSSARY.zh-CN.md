## 证据与工程术语

| 术语 | 通俗含义 | 不能据此证明什么 |
|---|---|---|
| 事实（Fact） | 带有来源和上下文的已记录事件或状态，不自动等于结论。 | 不能单独证明授权、正确性或生产就绪。 |
| 精确知识版本 | 一次判断实际使用的不可变知识身份、版本和摘要。 | 不能证明该知识普遍正确或当前一定适用。 |
| 治理判断 | 基于事实、知识和明确规则或边界进行的确定性计算。 | 不能自动产生现实动作权限。 |
| 证据（Evidence） | 支持检查和回放的材料。 | 不能单独等同于授权或最终真相。 |
| 授权（Authorization） | 由承担责任的人、组织或外部系统授予的权限。 | 不能证明动作已经执行或执行成功。 |
| 观察（Observation） | 有边界、可解释的发现。 | 不是自动处罚、生产命令或最终裁决。 |
| 回放（Replay） | 使用固定输入、版本和规则重建一次判断。 | 不能证明固定范围之外的一般兼容。 |
| UNKNOWN | 证据或知识不足时的显式结果。 | 不是隐藏成功，也不允许系统自行猜测。 |
| 路线图（Roadmap） | 计划中的方向。 | 不等于实现、验证或发布。 |

## 概念与架构术语

这些词用于解释设计意图。名称本身不会把概念升级成已实现能力。

| 术语 | 通俗含义 | 当前分类 |
|---|---|---|
| 悲悯协议 | 希望治理在可能时保留连续性、选择、差异和修复机会的设计原则。 | 概念与协议研究；工程能力必须回到具体合同、代码和测试。 |
| 细胞协议（Cell Protocol） | 系统或组织对自身身份、能力、边界和责任进行本地声明的候选机制。 | 已部分进入协议草案和示例；不代表生产级网络已经形成。 |
| 守护者网络（Guardian Network） | 用多个有边界的复核者替代单一无限裁决者的候选模型。 | 架构方向；不是已经部署的全球复核网络。 |
| 梦蝶 / 边界自知 | 对系统不确定性、解释范围和权限上限进行显式表达的隐喻。 | 概念来源；工程上必须由 `UNKNOWN` 等字段、规则和测试证明。 |
| 全频谱 / 全息递归 | 相似治理不变量可以在不同主体和组织尺度重复出现的研究视角。 | 非规范研究解释，不是运行证据。 |

对外说明能力时，请使用[证据与项目状态](https://github.com/full-spectrum-lab/full-spectrum-commons/blob/main/docs/evidence-and-status.md)中的状态词。

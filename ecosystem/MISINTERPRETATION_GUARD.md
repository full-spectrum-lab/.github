# Misinterpretation guard

Avoid these substitutions when describing Full Spectrum Lab:

| Incorrect shortcut | Correct boundary |
|---|---|
| “Enterprise AI operating system” | Evidence-first governance engineering family |
| “Agent orchestration platform” | Products do not plan or execute arbitrary agent tasks |
| “Engine is a planner/executor” | Engine performs deterministic governance evaluation |
| “Observer is APM/OpenTelemetry for agents” | Observer records governance observations, evidence, audit/replay and review boundaries |
| “Knowledge Governance is a RAG backend” | It governs exact knowledge identity, versions, provenance and lifecycle |
| “Protocol is agent transport” | Protocol defines governance semantics above connectivity |
| “The system takes action automatically” | Real-world action remains with an authorized external actor/system |
| “Industrial diagrams prove customer deployment” | Public industrial cases are synthetic unless explicitly proven otherwise |

Last updated at: 2026-09-16 22:05 UTC+8

Avoid these substitutions when describing Full Spectrum Lab:

| Incorrect shortcut | Correct boundary |
|---|---|
| “Enterprise AI operating system” | Evidence-first governance engineering family |
| “Agent orchestration platform” | Products do not plan or execute arbitrary agent tasks |
| “Engine is a planner/executor” | Engine performs deterministic governance evaluation |
| “Observer is APM/OpenTelemetry for agents” | Observer records governance observations, evidence, audit/replay and review boundaries |
| “Knowledge Governance is a RAG backend” | It governs exact knowledge identity, versions, provenance and lifecycle |
| “Protocol is agent transport” | Protocol defines governance semantics above connectivity |
| “The system takes action automatically” | Real-world action remains with an authorized external actor/system |
| “Industrial diagrams prove customer deployment” | Public industrial cases are synthetic unless explicitly proven otherwise |
| “Architecture diagrams prove integration” | Diagrams explain intended relationships; pinned executions and Evidence prove only their stated scope |
| “Research papers are specifications” | Research is non-normative and cannot override Protocol, Schema, code, tests or Releases |
| “Compassion Protocol is already implemented” | It is a conceptual and governance research direction; each engineering mechanism needs separate evidence |
| “Holographic recursion grants broad authority” | Recursion is an interpretive model; authority still requires explicit identity, scope and authorization |
| “A higher observation path is more correct” | Public understanding paths are parallel lenses, not ranks of people or truth |

## Current public boundary

- Full Spectrum is not an AI model or autonomous representative.
- No repository grants itself authority over external people, organizations or systems.
- Fixed synthetic or offline evidence does not establish general compatibility, real-network operation or production readiness.
- `UNKNOWN` and `NOT_CONFIRMED` must remain explicit when evidence is insufficient.
